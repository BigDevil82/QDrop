# 个人局域网模式

此模式面向同一 Wi-Fi 下的 Android 手机与 Windows 电脑，不经过公网服务器。Windows 电脑运行 QDrop API 和托盘接收器；手机准备分享内容后会自动发现当前网络中唯一已配对的 Windows 电脑并发送。

首次在每个地点各做一次配对：安装并启动 Windows 包，在设置窗口点击“初始化局域网并生成手机配对码”。Windows 会启动包内 FastAPI 服务、自动注册本机，并显示手机应填写的局域网地址和一次性注册码。Android 注册完成后保存该电脑的加密配对资料。办公室电脑和宿舍笔记本分别执行一次即可。

Windows 防火墙需允许包内 Python 的 TCP 8000 和 QDrop 的 UDP 48735，且仅限“专用网络”；首次出现系统防火墙提示时只勾选专用网络。UDP 48735 仅用于发现请求和不含凭据的地址响应；文件、令牌和传输状态均走 HTTP API。个人局域网模式允许 RFC1918 与 `100.64.0.0/10` 的局域网 HTTP，公共地址和域名 HTTP 仍被客户端拒绝。不要在公共 Wi-Fi 使用此模式。

日常使用时保持 Windows 的本地 API 与 QDrop 托盘程序运行。手机从分享页选 QDrop，或在 QDrop 输入文字/选择文件；应用会在约 1.2 秒内发现已配对电脑后自动发送。没有发现目标或发现多台已配对电脑时不会发送，避免误投递。

本地 API 使用 Windows 包内的 Python 3.12 与锁定依赖，不要求目标电脑另装 Python 或 Docker。退出 QDrop 时会关闭由它启动的本地服务。源码开发仍可用 `scripts/start-lan-server.ps1` 单独启动 API。
